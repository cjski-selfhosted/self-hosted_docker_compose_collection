# Hermes Agent

AI agent runtime with a browser chat interface.

[Compose file](docker-compose.yaml) · [Environment settings](.env.example) · [Usage](../README.md#usage)

## Configuration

- Use one HERMES_API_KEY for the agent API and WebUI.
- Keep shared workspace, state and code volume mappings aligned.
- Configure a model provider and initialise Hermes for a fresh installation.
